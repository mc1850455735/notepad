
# 第一阶段

**准备**
- 准备脚本部署项目, 以通过 docker 进行部署
- 在以 `Set` 集合类型的方法参数上, 添加 `@Params(参数名)` 以标记参数类型 (在 `IGroupBuyOrderDao` 中)
- 将前端代码放到 nginx 文件夹中, 在服务器上使用 nginx 进行部署
- 将构建号的项目打包成为镜像以便于在 docker 上进行部署
- 配置 dockerfile, 将编译后的 jar 包添加为 docker 中的应用, 构建名称要匹配 app 包中最终构建完成的 jar 包名称, 可以在 pom.xml 中进行设置.
- 通过 build.sh 中的 docker 命令, 完成对镜像的构建.

**流程**
- 使用 git clone -b 检出代码分支
- 使用 mvn clean install 清空后打包代码
- 执行 build.sh 利用写好的脚本执行 docker 镜像打包操作
- 通过 docker compose 使用指定配置部署打包好的 docker 镜像
- 安装完成后应开放服务器特定端口
