# 添加序列化方式

### Hessian
- 将数据转换为字节流, 通常比基于文本的转换方式, 如 `JSON`, `XML` 更高效
- 在网络传输和存储方面, 二进制格式相比文本格式占用更少带宽和存储空间
- dubbo 的默认序列化方式就是 Hessian

### Kryo
- Kryo 的设计目标是提供更高效, 更快速的序列化
- 相比 Java 自带的序列化机制, 如 Serializable 接口要高效的多
- Kryo 主要用来处理 Java 对象的二进制序列化, 常用于高性能, 低延迟的应用

### Protostuff
- 设计目标是提供比 Java 原生序列化机制更高效的二进制序列化解决方案
- 同时提供与其他流行的序列化框架相比更具有竞争力的性能

# SPI

**什么是SPI**
- SPI, 即 Service Provider Interface, 服务提供接口机制, 是 Java 提供的一种服务发现和扩展机制, 允许开发者在运行时根据需求动态加载和调用服务的具体实现.
- SPI 是一种松耦合的设计模式, 广泛应用于 Java 平台, 用于插件试架构的实现, 帮助系统在不修改核心代码的情况下扩展功能

**如何实现SPI**
- 首先, 在 resource 目录下创建 MATE-INF 包, 在这个包内创建 serializer 包
- 创建文件, 存放不同序列化方式对应的路径
