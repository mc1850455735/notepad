
# 保存 ChannelFuture
- 在 `RpcServer` 接口的 `start` 方法的实现中, 将 `serverBootstrap.bind` 函数执行返回的 `ChannelFuture` 类型变量保存为成员变量
- 该成员变量用于在 `RpcServer` 接口的 `stop` 实现方法中主动关闭服务端

# 实现stop方法
- 判断当前 channelFuture 是否为 null, 如果为 null, 说明服务尚未启动
- 不为 null, 则调用 `channelFuture.channel().close().sync()` 关闭服务器主通道, 确保所有连接均被释放
- 使用 `catch` 捕获 `InterruptedException` 异常并设置当前线程中断状态, 通过 `Thread.currentThread().interrupt()` 进行状态设置, 防止中断信号丢失
