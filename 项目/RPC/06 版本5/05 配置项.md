# 概述

**概述**
- 为避免硬编码, 使用配置项优化代码
- 当 RPC 工具被其他项目的消费者或者服务提供者引入时, 其他项目可能会根据环境进行自定义配置, 如选择序列化方式, 设置 Zookeeper 路径等

# 配置项实现

- 在 krpc-core 中创建一个 config 包, 创建 KRpcConfig 类, 用于保存配置信息
- 在 config 包中创建 RpcConstant 接口, 用于存储配置文件常量, 如前缀等
- 在 krpc-common 中创建一个 util 包, 创建 ConfigUtil 工具类用于加载配置文件, 判断是否加载成功, 是否使用默认环境等

# 维护全局对象

- 在 krpc-core 项目下创建一个 KRpcApplication 用于维护全局对象, 如配置类
- 在 consumer 和 provider 的 resources 下创建 `application.properties` 文件
- 该文件即为自定义配置文件, 用于定义用户自定义配置
- 使用 `ConfigUtil` 中的 `ConfigUtil.loadConfig` 读取并返回配置类对象
