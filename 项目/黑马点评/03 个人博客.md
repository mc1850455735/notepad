
# 发布笔记

- 对于一个评价类的记录, 通常表组织如下
- tb_blog: 探店笔记表, 包括笔记中的标题, 图片, 文字等
- tb_blog_comments: 其他用户对该笔记的评价
- 图片的上传与笔记的发送通常分为两个不同的请求, 因为对于图片上传到服务器的功能, 其他服务可能对此功能进行复用

# 点赞

**功能需求**
- 同一个用户只能点赞一次, 再次点击即取消点赞
- 如果当前用户已经点赞, 则点赞按钮进行高亮

**实现步骤**
- 给Blog类添加一个isLike字段, 标示是否被当前用户点赞过
```java
/**  
 * 是否点赞过了  
 */  
@TableField(exist = false)  
private Boolean isLike;
```
- 修改点赞功能, 利用Redis的Set集合判断是否点赞过, 未点赞过则点赞数+1, 已点赞过则点赞数-1
- 只有用户登录后才能进行点赞, 否则返回fail
```java
@Override  
public Result likeBlog(Long id) {  
    // 获取登录用户  
    // 如果当前用户未登录, 则不需要考虑登录状态  
    UserDTO user = UserHolder.getUser();  
    if(user == null) {  
        return Result.fail("请在登陆后点赞");  
    }
    // 判断当前用户是否已经点赞  
    String key = "blog:liked:" + id;  
    Boolean isMember = stringRedisTemplate.opsForSet().isMember(key, user.getId());
    // 修改点赞数量  
    if (!isMember) {  
        // 未点赞, 则可以点赞, 数据库点赞数+1, 保存用户到Redis的set集合  
        boolean isSuccess = update().setSql("liked = liked + 1").eq("id", id).update();  
        if (isSuccess) {  
            stringRedisTemplate.opsForSet().remove(key, user.getId().toString());  
        }  
    } else {  
        // 已点赞, 则取消点赞, 数据库点赞数-1, 将用户从set集合中删除  
        boolean isSuccess = update().setSql("liked = liked - 1").eq("id", id).update();  
        if (isSuccess) {  
            stringRedisTemplate.opsForSet().add(key, user.getId().toString());  
        }  
    }  
    return Result.ok();  
}
```
- 将对Blog的是否点赞赋值功能封装成一个函数
```java
private void isBlogLiked(Blog blog) {  
    String key = "blog:liked:" + blog.getId();  
    Long userId = blog.getUserId();  
    Boolean isMember = stringRedisTemplate.opsForSet().isMember(key, userId.toString());  
    blog.setIsLike(isMember);  
}
```
- 修改根据id查询Blog的业务, 判断当前用户是否点赞过, 赋值给isLike字段
```java
@Override  
public Result queryBlogById(Long id) {  
    // 查询Blog  
    Blog blog = getById(id);  
    // 查询Blog有关的用户  
    queryBlogUser(blog);  
    // 查询Blog是否被当前用户点赞  
    isBlogLiked(blog);  
    return Result.ok(blog);  
}
```
- 修改分页查询字段, 判断当前登录用户是否点赞过
```java
@Override  
public Result queryHotBlog(Integer current) {  
    // 根据用户查询  
    Page<Blog> page = query()  
            .orderByDesc("liked")  
            .page(new Page<>(current, SystemConstants.MAX_PAGE_SIZE));  
    // 获取当前页数据  
    List<Blog> records = page.getRecords();  
    // 查询用户  
    records.forEach((blog)->{  
        queryBlogUser(blog);  
        isBlogLiked(blog);  
    });  
    return Result.ok(records);  
}
```

# 点赞排行榜

- 原有的Set集合判断是否点赞的实现无法满足现有的排行榜需求
- 如果使用SortedSet, 则可以在排序的基础上实现一个集合
	- SortedSet没有ismember函数, 可以通过zscore查询元素, 如果查询失败, 说明不存在对应元素
	- 通过SortedSet的zrange, 可以查找指定范围内的元素, 天然实现查找前N个元素的目的

**代码实现**
- zscore查询是否存在元素

- 使用zrange查询并返回top5
```java
@Override  
public Result queryBlogLikes(Long id) {  
    String key = BLOG_LIKED_KEY + id;  
    // 使用zrange查询top5用户  
    Set<String> top5 = stringRedisTemplate.opsForZSet().range(key, 0, 4);  
    // 避免为空集合  
    if(top5 == null || top5.isEmpty()) {  
        return Result.ok(Collections.emptyList());  
    }  
    List<Long> ids = top5.stream().map(Long::valueOf).toList();  
    String idsStr = StrUtil.join(",", ids);  
    List<UserDTO> userDTOS = userService  
            .query()  
            .in("id", ids)  
            .last("Order By Field(id, " + idsStr + ")")  
            .list()  
            .stream()  
            .map((user) -> BeanUtil.copyProperties(user, UserDTO.class)).toList();  
    return Result.ok(userDTOS);  
}
```

**注意**
- 对于MyBatisPlus提供的`listById`, 其内部实现是通过`in`关键字, 判断某元素是否在对应的列表中进行查询的
- 在MySQL查询时, 使用in查询得到的结果是不按in中字段顺序排序的, 导致最终根据正确顺序id得到的user结果反而是不正确的
- 为了使最终查询结果正确, 需要使用`order by`关键字配合`field()`函数
```java
String idsStr = StrUtil.join(",", ids);
userService.query().in("id", ids).last("ORDER BY FIELD(id, " + idsStr);
```
