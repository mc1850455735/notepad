### PyTorch两大辅助函数

	- 展示pytorch中有什么功能

### 三种代码编写方式
- py文件
	- 单个py文件为一块, 会从头到尾执行, 出现错误后重新运行必须从头开始
- 控制台
	- 控制台中以每一行为一块, 一行出现错误可以单独执行某一行, 但可阅读行差
- jupyter笔记
	- 使用jupyter notebook在当前路径下打开笔记管理页面
	- 在文档中, 每一个代码块作为一块, 出现错误后, 可以单独执行某一块, 且阅读性较好

### 代码实战

- 创建自己的数据读取类 `MyData`
	- `__init__` : 为自己的类提供一些变量和方法
	- `__getitem__(self, index)` : 读取数据的方法
		- `from PIL import Image` : 用于读取图片
- 自动拼接系统路径 : `os.path.join(root_dir, label_dir)`

```python
from torch.utils.data import Dataset  
from PIL import Image  
import os  
  
class MyData(Dataset):  
    def __init__(self, root_dir, label_dir):  
        # 使其称为全局变量  
        self.root_dir = root_dir  
        self.label_dir = label_dir  
        self.path = os.path.join(self.root_dir, self.label_dir)  
        self.image_path = os.listdir(self.path)  
  
  
    def __getitem__(self, idx):  
        img_name = self.image_path[idx]  
        img_item_path = os.path.join(self.path, img_name)  
        # 读取图片  
        img = Image.open(img_item_path)  
        label = self.label_dir  
        return img, label  
  
    def __len__(self):  
        return len(self.image_path)  
  
  
root_dir = "dataset/train"  
ant_label_dir = "ants"  
bee_label_dir = "bees"  
ants_dataset = MyData(root_dir, ant_label_dir)  
bees_dataset = MyData(root_dir, bee_label_dir)  
# 读取到的两数据集之和  
train_dataset = ants_dataset + bees_dataset
```

# TensorBoard和transforms

### TensorBoard

**TensorBoard概述**
- TensorBoard 一个模型训练可视化工具，主要作用是帮助在训练深度学习模型时观察和分析训练过程中的各种指标和数据
- TensorBoard最初于TensorFlow中加入, PyTorch后期也加入了TensorBoard的工具类

**TensorBoard 的使用**
- `SummaryWriter` 直接向log_dir中写入可以被TensorBoard解析的事件文件
	- 可以指定log_dir位置, 默认为当前位置
- `writer.add_scalar()` : 向文件中添加一个刻度
	- `scalar_value` : y轴  
	- `global_step` : x轴
	- `tag` : 图像的名称
- `writer.add_image()` : 向文件中添加一个图片
	- `tag` : 生成图像的名称
	- `img_tensor` : 欲加入的图片(`torch.Tensor, numpy.ndarray, or string/blobname`)
	- `global_step` : 步骤数 (x轴)
	- 要求加入的图像尺寸的排列方式为 ( `C, H, W`  - 通道数, 高度, 宽度), 如果排列方式不为默认要求, 需要通过 `dataformats` 参数进行设置


**示例01** : 建立一个y=x的图像
- 相同tag重复执行`add_scalar`时, 会将新生成的数据加入原来的文件, 并由TensorBoard尝试对其拟合, 导致图像与预期不符
- 解决方法为删除所有的图像文件, 并重新打开TensorBoard进程, 即可重置所有的图像
```python
from torch.utils.tensorboard import SummaryWriter  
writer = SummaryWriter("logs") 
# y = x  
for i in range(100):  
    writer.add_scalar("y=x", i, i) 
writer.close()
```
- 查看生成的图像
- `tensorboard --logdir=logs` : 设置事件文件所在文件夹为当前路径下的logs文件夹, 进入对应网址(默认ttp://localhost:6006/ )进行查看
- 通过 `--port` 参数设置, 控制生成图像服务端所在的端口, 避免同一台服务器多人使用时出现冲突情况

**示例02** : 将图像加入tensorboard
- 同样的, 对一个文件多次连续加入会在其x轴上进行拓展
```python
from torch.utils.tensorboard import SummaryWriter  
import numpy as np  
from PIL import Image  
  
writer = SummaryWriter("logs")  
img_path = "dataset/train/ants_image/0013035.jpg"  
img_PIL = Image.open(img_path)  
img_array = np.array(img_PIL)  

writer.add_image("test", img_array, 1, dataformats="HWC") 

writer.close()
```

### Transforms

**简述**
- transforms中含有许多工具类, 用于图片处理和变换, 如中心裁剪, tensor转换等, 使用对应工具处理后, 可以将图片处理成为预期的结果
- `ToTensor` : 创建相应的工具对象, 使用时传入一个PIL或numpy图片, 将其转换为tensor类型

**使用示例**
```mysql
from torchvision import transforms  
from PIL import Image  

img_path = 'dataset/train/ants_image/0013035.jpg'  
image = Image.open(img_path)  
tensor_trans = transforms.ToTensor()  
tensor_img = tensor_trans(image)  
  
print(tensor_img)
```
