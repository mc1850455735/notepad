



GPT (Generative Pre-trained Transformer，生成式预训练 Transformer 模型) 是一种基于 Transformer Decoder 的生成式自回归预训练语言模型。他的核心训练目标是是 next-token prediction，也就是根据前面的上下文预测下一个 token。通过在大规模文本语料上进行预训练，GPT 可以学习语法、语义、知识以及一定的推理和生成能力。由于它采用 Decoder-only 架构，并使用 causal mask 保证只能看到历史上下文，因此特别适合文本生成任务。现代 GPT 模型通常还会结合 SFT 和 RLHF/DPO 等对齐方法，使模型更擅长遵循指令、进行对话并符合人类偏好。它的优势是通用性强、任务统一，但也有幻觉、时效性和推理稳定性等挑战。

# 概念

GPT，即 Generative Pre-trained Transformer。

GPT 是 Generative Pre-trained Transformer 的缩写，中文可以理解为生成式预训练 Transformer 模型。它是现代大语言模型最核心的一条技术路线之一，特点是：先在海量文本上做预训练，学会语言规律、知识和推理模式，再通过后续微调或对齐，让模型更适合真实任务。

**G**
即 Generative，表示该模型是一个生成式模型，说明其核心能力在于生成后续文本。

**P**
Pre-trained，表示它先经过预训练，已经在海量文本数据上学习了大量语言模式、常识知识和表达方式。

**T**
Transformer，表示它的底层结构是 Transformer。GPT 采用的是 Transformer Decoder-only 结构。

# GPT 架构

GPT 基于 Transformer Decoder，是一个 Decoder-only Transformer，这意味着它特别适合做从左到右的自回归生成。

这句话里其实已经包含了 GPT 的几个关键点：

- 基于 Transformer
- 用 Decoder 架构
- 自回归
- 预训练
- 下一个 token 预测
- 擅长生成任务

为什么 Decoder-only 很适合生成，因为 GPT 的训练方式是 根据前面的上下文，预测下一个 token 是什么，这和真实生成过程完全一致。训练时这样学，推理时也这样生成，所以范式是统一的。

- **BERT** 更偏理解，Encoder-only，双向建模
- **GPT** 更偏生成，Decoder-only，自回归建模

# GPT 预训练过程

## 预训练：Next Token Prediction

GPT 最核心的训练目标是： 给定前面的 token，预测下一个 token。

这个过程叫 **自回归语言建模**，Causal Language Modeling。它本质上是在最大化文本序列的条件概率。

## 为什么只做 next-token prediction 就这么强

GPT 的一个核心思想是，足够大规模的 next-token prediction 本身就能诱导出通用语言理解和生成能力。

如果训练数据足够大、模型足够大，那模型为了更准确预测下一个词，就不得不学会 语法、语义、事实知识、逻辑模式、长程依赖、多任务格式、推理模式、代码结构 等。

所以虽然表面上目标很简单，但它逼着模型学到非常丰富的能力。

# GPT 的输入输出方式

## 输入

输入通常是一串 token 序列。

## 输出

输出是下一个 token 的概率分布。在推理时，再根据这个分布去采样或选择 token，逐步生成完整文本。

# GPT 的关键技术点

## 1. 自注意力机制

GPT 继承了 Transformer 的核心机制：**Self-Attention**。

它的作用是：
- 在生成每个 token 时，动态关注前面上下文中最相关的部分
- 建立长距离依赖关系

例如在长句子中，一个词可能和前面很远的词相关，  
Self-Attention 比 RNN 更容易捕捉这种依赖。

## 2. 位置编码

因为 Transformer 本身不天然理解顺序，所以要加入位置信息，让模型知道哪个 token 在前，哪个 token 在后。

## 3. Masked Self-Attention / Causal Mask

GPT 是**自回归模型**，所以在训练时不能偷看未来词，例如预测第 5 个 token 时，只能看前 4 个 token，不能看后面的内容。

GPT 使用带因果掩码的自注意力机制，保证每个位置只能访问当前位置之前的上下文，从而符合自回归生成的要求。

# GPT vs BERT

- GPT 更适合生成式任务，因为训练目标和生成过程天然一致
- BERT 更适合理解类任务，因为它能同时利用左右上下文做表示学习。

| 维度     | GPT                        | BERT                   |
| -------- | -------------------------- | ---------------------- |
| 架构     | Decoder-only               | Encoder-only           |
| 建模方式 | 自回归，从左到右           | 双向建模               |
| 训练目标 | Next-token prediction      | Masked LM              |
| 强项     | 文本生成、对话、写作、代码 | 理解、分类、抽取、匹配 |
| 推理方式 | 逐 token 生成              | 一次性编码整句         |

# GPT 为什么这么强

GPT 的成功很大程度上来自于“简单目标 + 大规模训练 + 强大模型容量”这套范式。

1. 大规模数据：海量文本让它学到丰富知识和语言模式。
2. 大模型参数：参数量足够大，模型容量足够强。
3. Transformer 架构：Self-Attention 能有效建模长距离依赖。
4. 统一任务范式：很多任务都可以转成“给定上下文，继续生成”的形式。
	- 问答：问题后面接答案
	- 翻译：输入原文后输出译文
	- 摘要：输入文章后输出摘要
	- 分类：输入文本后输出类别标签
	- 代码：输入需求后输出代码
1. Scaling Law：随着参数、数据和计算量扩大，模型性能会持续提升。

# GPT 训练后流程

# GPT 局限

## 1. 幻觉问题

GPT 生成的内容不一定都真实，可能会编造事实。

## 2. 推理不稳定

复杂逻辑推理和数学推理并不总是可靠。

## 3. 知识时效性有限

如果不接外部工具或检索，模型知识停留在训练数据覆盖范围内。

## 4. 成本高

大模型训练和推理成本都很高。

## 5. 可解释性弱

很难严格解释模型为什么给出某个答案。

# GPT 的发展脉络

### GPT-1

证明了“预训练 + 微调”在 NLP 中有效。

### GPT-2

展示了更大规模语言模型的强生成能力。

### GPT-3

把 in-context learning 推到一个新阶段，很多任务不微调也能做。

### 后续 GPT 类模型

进一步结合：
- instruction tuning
- RLHF / DPO
- tool use
- multimodal
- reasoning enhancements

# 为什么 GPT 可以做这么多任务

很多任务都可以转化成文本到文本的生成问题，而 GPT 的训练目标正是根据上下文继续生成后续内容。所以只要通过 prompt 把任务描述清楚，模型就能在统一框架下完成问答、翻译、总结、代码生成等多种任务。
