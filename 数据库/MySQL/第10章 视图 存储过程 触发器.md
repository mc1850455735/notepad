# 视图

### 视图概述

**介绍**
- **视图(View)** 是一种虚拟存在的表. 
- 视图中的数据并不在数据库中真实存在, 行和列的数据来自定义视图的查询中使用的表, 这个表又被称为**基表** , 并且是在使用视图时动态生成的
- 视图只保存了查询的SQL逻辑, 不保存查询结果, 所以创建视图的主要工作在于创建SQL查询语句

**创建**
- select语句中就是视图所关联的基表
- `or replace` : 如果该视图已存在, 则替换该视图
```mysql
create [or replace] view 视图名称[(列名列表)] as select语句 [with [cascaded | local] check option ]
```
**示例**
```mysql
create or replace view v_stu_1 as  
select id, name  
from student  
where id <= 10;
```

**查看创建视图语句**
```mysql
show create view 视图名称;
```

**查询视图数据**
```mysql
select * from 视图名称 ...;
```
**示例**
```mysql
select * 
from v_stu_1;
```

**修改视图**
- 方式一
- 用作修改视图时, or replace 必须加
```mysql
create or replace view 视图名称[(列表名称)] as select语句 [with [cascaded|local] check option]
```
- **示例**
```mysql
create or replace view v_stu_1 as 
select id, name 
from student 
where id <= 5;
```

- 方式二
```mysql
alter view 视图名称[(列表名称)] as select语句 [with [cascaded|local] check option]
```
- **示例**
```mysql
alter view v_stu_1 as 
select id, name, no 
from student 
where id <= 7;
```

**删除**
```mysql
drop view [if exists] 视图名称 [, 视图名称]...
```
**示例**
```mysql
drop view if exists v_stu_1;
```

### 视图检查选项

- 可以通过视图向表中插入数据
- cascaded或local选项会检查视图创建时的条件
- 如果插入的数据不符合创建时筛选条件的，插入就会失败。

**示例**
```mysql
insert into stu_v_1
values (6, 'Tom');
```

##### 视图cascaded
- 视图在创建时, 可能存在某些限制条件, 如id的范围, 对应的性别等, 如果对通过视图插入的值不做限制, 可能出现插入成功但视图中无法访问的情况
- 当使用`with check option`子句创建视图时，MySQL会通过视图检查正在更改的每个行，以使其符合视图的定义
- MySQL允许基于另一个视图创建视图，还会检查视图中的规则以保持一致性
- 为了确定检查的范围, 可以通过`cascaded`或`local`进行范围检查, 范围检查的默认值为`cascaded`

**使用**
- 假设v2视图使用了v1视图作为基表，v2视图添加了`cascaded`选项，则既检查v2的条件，也检查v1的条件
- 如果使用了`cascaded` , 那么即使基表视图中没有使用`with check option`, 也会对视图的条件进行检查
- `cascaded`会检查视图的基表中的数据，对于以当前表作为基表的视图，`cascaded`不会进行检查，只有当值被传递到有检查的视图时，才会进行检查

**示例**
```mysql
-- 视图v1
create or replace view v_stu_1 as  
select id, name  
from student  
where id <= 20;
-- 以v1为基表的视图v2
create or replace view v_stu_2 as  
select id, name  
from v_stu_1  
where id >= 10  
with cascaded check option;
-- 插入, 不符合v2条件, 失败
insert into v_stu_2 values (7, 'Jerry');
-- 插入, 符合v2, 但是由于检查的继承性, 不符合v1, 失败
insert into v_stu_2 values (22, 'Jerry');
-- 插入, 既符合v2, 也符合v1, 成功
insert into v_stu_2 values (16, 'Mike');
-- 基于v2, 建立视图v3, 不添加视图检查选项
create view v_stu_3 as select id, name from v_stu_2 where id <= 15;
-- 插入, 满足v3条件, 也满足v2条件, 成功
insert into v_stu_3 values (11, 'Jerry');
-- 插入, 不满足v3条件, 满足v2条件, 但v3没有检查选项, 插入成功
insert into v_stu_3 values (17, 'Jerry');
-- 插入, 不满足v3条件, 也不满足v2条件, 插入失败
-- 在v2的检查选项中被排除
insert into v_stu_3 values (28, 'Mike');
-- 插入, 满足v3条件, 不满足v2条件, 插入失败
-- 在v2的检查选项中被排除
insert into v_stu_3 values (7, 'Marry');
```

##### 视图local
- 对于local条件，则只会检查当前视图的条件，如果基表中没有定义视图检查选项, 则不会继续检查基表的条件
- 如果基表有检查选项, 则进行检查, 否则不进行检查
**示例**
```mysql
-- 创建v4, 不加检查选项
create view v_stu_4 as  
select id, name  
from student  
where id <= 15;
-- v4无检查选项, 插入全部成功
insert into v_stu_4 values (5, 'Tom');  
insert into v_stu_4 values (16, 'Tom');  

-- 创建v5, 基表为视图v4, 添加local检查选项
create or replace view v_stu_5 as  
select id, name  
from v_stu_4  
where id >= 10  
with local check option;  
-- 插入, 满足v5条件, 不满足v4条件, 不做递归检查, 插入成功
insert into v_stu_5 values (17, 'Tom');  
-- 插入, 不满足v5条件, 插入失败
insert into v_stu_5 values (7, 'Tom');  

-- 创建v6, 基表为视图v5, 不加检查选项
create view v_stu_6 as  
select id, name  
from v_stu_5  
where id < 20;
-- 符合v4, v5, v6, 插入成功
insert into v_stu_6 values (14, 'Tom');
-- 符合v5, 不符合v4, v6, 但是只有v5有local检查选项, 插入成功
insert into v_stu_6 values (21, 'Tom');  
-- 不符合v5, 插入失败
insert into v_stu_6 values (7, 'Tom');
```

### 视图更新

- 要使视图可以更新，视图中的行和基础表中的行必须存在**一对一**的关系
- 如果视图包含以下项，则不可更新
	1. 聚合函数或窗口函数
	2. `distanct`
	3. `group by`
	4. `having`
	5. `union`或`union all`
**示例**
```mysql
-- 创建视图, 使用聚合函数  
create view v_stu_cnt as select count(*) from student;
-- 试图修改使用聚合函数的视图, 失败
insert into v_stu_cnt values (10);
```


### 视图作用

- 操作简单
	- 视图不仅可以简化用户对数据的了解, 也可以简化他们的操作
	- 经常被使用的查询可以被定义为视图, 从而使得用户不必为以后的操作每次都指定全部的条件
- 安全 
	- 数据库只能授权到表，不能授权到数据库特定行和特定列上, 安全性方面受到限制
	- 通过视图可以限制用户可以看到的行和列, 用户只能查询和修改他们所能看到的数据
- 数据独立
	- 视图可以帮助用户屏蔽基表变化带来的影响
	- 当基表发生变化时, 只需要修改视图对应的查询语句, 而不需要改变用户所能看到的接口

**示例**
- 01 : 为了保证数据库表的安全性, 开发人员在操作tb_user表时, 只能看到用户的基本字段, 屏蔽手机号和邮箱两个字段
```mysql
-- 创建视图
create view v_tb_user as  
select id, name, profession, age, gender, status, createtime  
from tb_user;
-- 查询
select * from v_tb_user;
```
- 02 : 查询每个学生选修的课程(三表联查) , 由于该功能使用较多, 定义一个视图表示这个查询过程
```mysql
-- 创建视图
create or replace view v_student_course as  
select s.name student_name, s.no student_no, c.name course_name  
from student s,  
     course c,  
     student_course sc  
where s.id = sc.studentid  
  and c.id = sc.courseid;
-- 查询
select * from v_student_course;
```

# 存储过程

### 存储过程概念

**介绍**
- 存储过程是事先经过编译并存储在数据库中的一段SQL语句的集合
- 通过调用存储过程可以简化开发工作，减少数据在数据库与服务器之间的重复传输，提高数据处理效率
- 存储过程在思想上就是数据库SQL语言层面的的代码封装与重用

**特点**
- 封装、复用
- 既可以接收参数，也可以返回数据
- 减少网络交互，效率提升

### 存储过程语法

**创建**
- 注意, 在命令行中, 执行创建存储过程的SQL时, 需要通过关键字`delimiter`指定SQL语句的结束符
- 如 : `delimiter $$` -> 以双dollar符作为语句的结尾
```MYSQL
CREATE PROCEDURE 存储过程名称([参数列表])
BEGIN
    -- SQL语句
END;
```
示例
```mysql
create procedure p1()  
begin  
    select count(*) from student;  
end;
```

**调用**
```mysql
CALL 名称([参数])
```

**查看**
```mysql
-- 查询指定数据库的存储过程以及状态信息
select * from information_schema.routines where routine_schema = 'xxx';
-- 查询某个存储过程的定义
show create procedure 存储过程名称;
```

**删除**
```mysql
drop procedure [if exists] 存储过程名称;
```

### 存储过程变量

##### 系统变量
- 系统变量是MySQL服务器提供的, 不是用户定义的, 属于服务器层面
- 系统变量分为全局变量(`GLOBAL`)和会话变量(`SESSION`)
	- 如果不指定级别, 默认为session级别
- 即使设置完全局系统变量, 数据库系统重启后, 全局系统变量仍然会被置为默认值
	- 如果想要不失效, 应该修改 `/etc/my.cnf` 中的配置文件

**查看系统变量**
```mysql
-- 查看所有系统变量
show [session | global] variables;
-- 通过模糊查询匹配变量
show [session | global] variables like '...';
-- 查看指定变量的值
select @@[session.|global.]系统变量名;
```

**设置系统变量**
```mysql
set [session | global] 系统变量名=值;
set @@[session.|global.] 系统变量名=值;
```

##### 用户自定义变量
- **用户自定义变量**是用户根据需要自己定义的变量, 用户变量不需要提前声明, 在用的时候直接用 `@变量名` 使用就可以
	- 两个( `@@` )为系统变量, 一个( `@` )为用户自定义变量
- 用户定义的变量无需对其进行声明或初始化, 只是直接获取到的值为NULL, 并不会报错
- 其作用域为当前连接/会话

**赋值**
- 使用 `=` 或者 `:=` 都可以进行赋值
- 推荐使用 `:=` 进行赋值, 因为 `=` 在MySQL当中有判断是否相等的用途存在
```mysql
set @var_name=expr, [@var_name=expr] ...;
set @var_name:=expr, [@var_name:=expr] ...;
```
- 可以在select中使用into关键字, 将查询结果作为变量保存起来
```mysql
select @var_name:=expr [, @var_name:=expr] ...;
-- 将指定查询的结果赋值给用户自定义变量
select 字段名 into @var_name from 表名;
```

**使用**
```mysql
select @变量名;
```

**示例**
```mysql
-- 使用set赋值
set @myname = 'majinliang';  
set @myage := 20;  
set @mygender := '男', @myhobby := 'java';  
-- 使用select赋值
select @mycolor := 'red';
-- 将count(*)查询结果作为用户自定义变量存储起来
select count(*) into @mycount from tb_user;
-- 查询  
select @myname, @myage, @mygender, @myhobby;  
select @mycolor, @mycount;
```

##### 局部变量
- 局部变量是根据需要定义的在局部生效的变量, 访问之前需要`DECLARE`声明
- 可用作存储过程内的局部变量和输入参数, 局部变量的范围是在其内声明的`BEGIN...END`块

**声明局部变量**
- 变量类型就是数据库字段类型, 如int, bigint, varchar, date等等
- default关键字可以用于给局部变量指定默认值
```mysql
declare 变量名 变量类型[default ...];
```

**赋值**
```mysql
set 变量名=值;
set 变量名:=值
select 字段名 into 变量名 from 表名 ...;
```

**示例**
```mysql
-- 创建存储过程
create procedure p2()  
begin
    -- 声明局部变量
    declare stu_count int;  
    select count(*) into stu_count from student;  
    select stu_count;  
end;  
-- 调用存储过程
call p2();
```

### 流程控制

##### if语句
```mysql
if 条件1 then
    ...
elseif 条件2 then
    ...
else
    ...
end if;
```

**示例** : 使用if, 根据score判断分数等级
```mysql
create procedure p3()  
begin  
    declare score int default 58;  
    declare result varchar(10);  
    if score >= 80 then  
        set result := '优秀';  
    elseif score >= 60 then  
        set result := '及格';  
    else  
        set result := '不及格';  
    end if;  
    select result;  
end;  
call p3();
```

##### case语句

**语法1**
```mysql
case case_value
    when when_val1 then statement_list1
    [when when_val2 then statement_list2]
    [else statement_list]
end case;
```

**语法2**
```mysql
case 
    when search_condition1 then statement_list1
    [when search_condition2 then statement_list2]
    [else statement_list]
end case;
```

**示例01** : 根据传入的月份, 判断月份所属的季节 (使用case)
```mysql
create procedure p6(in month int)  
begin  
    declare season varchar(10);  
    case  
        when month >= 1 and month <= 3 then  
            set season = '第一季度';  
        when month >= 4 and month <= 6 then  
            set season = '第二季度';  
        when month >= 7 and month <= 9 then  
            set season = '第三季度';  
        when month >= 10 and month <= 12 then  
            set season = '第四季度';  
        else  
            set season = '非法输入';  
    end case;  
    select concat('您输入的月份为: ', month, ', 所属季度为: ', season);  
end;
```

##### while循环
- while循环是有条件的循环控制语句, 满足条件后, 再执行循环体中的SQL语句

**语法**
```mysql
while 条件 do
    -- sql逻辑
end while;
```

**案例01** : 计算从1累加到n的值, n为传入的参数
```mysql
create procedure p7(in n int)  
begin  
    declare total int default 0;  
    while n > 0 do  
        set total := total + n;  
        set n = n - 1;  
    end while;  
    select total;  
end;  
call p7(10);
```

##### repeat循环
- repeat是有条件的循环控制语句, 当满足条件时退出循环
- 先执行一次循环, 再判断until中的逻辑判断是否满足, 如果满足则退出循环

**语法**
```mysql
repeat 
    -- SQL逻辑
    until 条件;
end repeat;
```

**案例** : 计算从1累加到n的值, n为传入的参数(使用repeat)
```mysql
create procedure p8(in n int)  
begin  
    declare total int default 0;  
    repeat  
        set total := total + n;  
        set n := n - 1;  
    until n <= 0  
    end repeat;  
    select total;  
end;
```

##### loop循环
- loop可以用以实现简单的循环, 如果不在loop中的SQL逻辑中添加退出循环的条件, 则可以用来实现简单的死循环
- loop可以配合以下两个语句使用
	- `leave` : 配合循环使用. 退出当前循环
	- `iterate` : 配合循环使用. 跳出当前循环, 进入下次循环

**语法**
- 循环
```mysql
[begin_label:] loop
    -- SQL逻辑
end loop [end_label];
```
- 流程控制
```mysql
-- 退出指定标志的循环体
leave label;
-- 直接进入下一次循环
iterate label;
```

**示例01** : 计算从1到n累加值, n为传入的参数值
```mysql
create procedure p9(in n int)  
begin  
    declare total int default 0;  
    sum:loop  
        if n < 0 then  
            leave sum;  
        end if;  
        set total := total + n;  
        set n := n - 1;  
    end loop sum;  
end;
```
**示例02** : 计算从1到n之间偶数的累加值, n为传入的参数值
```mysql
create procedure p10(in n int)  
begin  
    declare total int default 0;  
    sum:loop  
        if n < 0 then  
            leave sum;  
        end if;  
        if n%2 = 1 then  
            set n := n - 1;  
            iterate sum;  
        end if;  
        set total := total + n;  
        set n := n - 1;  
    end loop sum;  
    select total;  
end;
```

### 存储过程参数

- in (默认) : 该类参数作为输入, 也就是需要调用时传入值
- out : 该类参数作为输出, 也就是该参数可以作为返回值
- inout : 既可以作为输入参数, 也可以作为输出参数

**用法**
```mysql
create procedure 存储过程名称([in/out/inout 参数名 参数类型])
begin
    -- SQL语句
end;
```

**示例01** : 根据传入的score分数, 判定分数等级并返回
- 返回值使用一个用户自定义变量(`@变量名`)进行接收
```mysql
create procedure p4(in score int, out result varchar(10))  
begin  
    if score >= 80 then  
        set result := '优秀';  
    elseif score >= 60 then  
        set result := '及格';  
    else  
        set result := '不及格';  
    end if;  
end;  
call p4(38, @result);  
select @result;
```
**示例02** : 根据传入的200分制分数, 进行换算称为百分制并返回
```mysql
create procedure p5(inout score double)  
begin  
    set score := score / 2;  
end;  
set @score = 198;  
call p5(@score);  
select @score;
```

### 游标cursor

**概念**
- 在之前定义的一些类型的变量, 如int, double, varchar, 只能用于接收一些单行单列类型的数据, 如果试图通过变量存储一行查询结果或者一张表, 则无法进行存储, 这时就会用到游标cursor
- **游标(cursor)** 是用来存储查询结果集的数据类型, 在存储过程和函数中可以使用游标对结果集进行循环的处理
- 游标的使用包括游标的**声明**, **open**, **fetch** 和 **close**, 语法如下

**声明游标**
- 需要把哪个查询语句结果封装到游标中, 查询语句就写什么
- 普通变量的声明必须写在游标声明之前
```mysql
declare 游标名称 cursor for 查询语句;
```

**打开游标**
- 使用游标之前, 必须要打开游标
```mysql
open 游标名称;
```

**获取游标数据**
- 使用循环获取游标数据时, 每循环一次, 就从游标中获取到一行的数据
- 当游标中已没有数据, 但仍继续试图获取数据时, 存储过程语句会报错
- 可以通过handler语句解决这种报错
```mysql
fetch 游标名称 into 变量[,变量];
```

**关闭游标**
```mysql
close 游标名称;
```

**案例** : 根据传入的参数uage, 查询用户表tb_user中, 所有用户年龄小于等于uage的用户姓名(name)和专业(profession), 并将用户的姓名和专业插入到所创建的一张新表中
- 通过handler语句处理游标为空异常, 关闭游标后, 使其正常退出
```mysql
create procedure p11(in uage int)  
begin  
    -- 声明游标  
    declare uname varchar(100);  
    declare uprofession varchar(100);  
    declare u_cursor cursor for select name, profession from tb_user where age <= uage;  
    declare exit handler for SQLSTATE '02000' close u_cursor;  
  
    drop table if exists tb_user_pro;  
    create table if not exists tb_user_pro (  
        id int primary key auto_increment,  
        name varchar(100),  
        profession varchar(100)  
    );  
    -- 开启游标  
    open u_cursor;  
    while true do  
        fetch u_cursor into uname, uprofession;  
        insert into tb_user_pro values (null, uname, uprofession);  
    end while;  
end ;
```


### 条件处理程序handler
- 条件处理程序(Handler)可以用来定义在流程控制结构执行过程中遇到问题时的相应处理步骤

**语法**
- handler_action
	- `continue` : 继续执行当前程序
	- `exit` : 终止执行当前程序
- condition_value
	- `SQLSTATE sqlstate_value` : 状态码, 如02000
	- `SQLWARNING` : 所有以01开头的SQLSTATE代码的简写
	- `NOT FOUND` : 所有以02开头的SQLSTATE代码的简写
	- `SQLEXCEPTION` : 所有没有被 `SQLWARNING` 或 `NOT FOUND` 捕获的 `SQLSTATE`代码的简写
- MySQL官方文档中描述了每一种状态码的含义
	- 02000 : 找不到数据
	- 可以直接以`NOT FOUND`来简化游标数据用尽时的开发
```mysql
declare handler_action handler for condition_value[, condition_value]... statement;
```

**示例** : 如果游标为空, 则退出并关闭游标
- 状态码写法
```mysql
declare exit handler for SQLSTATE '02000' close u_cursor;
```
- `NOT FOUND`写法
```mysql
declare exit handler for not found close u_cursor;
```

### 存储函数

**概念**
- 存储函数是有返回值的存储过程, 可以直接被select使用
- 使用存储函数的地方都可以使用存储过程进行替代
- 存储函数的参数只能是in类型的

**语法**
- `characteristic` 说明
	- `deterministic` : 输入相同的参数总是获得相同的结果
	- `no sql` : 不包含sql语句
	- `read sql data` : 包含读取数据的语句, 但是不含写入数据的语句
- 在MySQL8.0及以上版本默认开启二进制日志, 一旦开启二进制日志, 则要求当前存储函数必须描述特性 `characteristic`
```mysql
create fucntion 存储函数名称([参数列表])
returns type [characteristic ...]
begin
   -- SQL语句
   return ...;
end;
```

**案例** : 计算从1到n累加的值, 使用存储函数实现
```mysql
create function fun1(n int)  
returns int deterministic  
begin  
    declare total int default 0;  
    while n > 0 do  
        set total := total + n;  
        set n := n - 1;  
    end while;  
    return total;  
end;
select fun1(100);
```

# 触发器

### 触发器概念

- 触发器是一种与表有关的数据库对象, 指在insert/update/delete操作之前或之后, 触发并执行触发器中定义的**SQL语句集合**
- 触发器的这种特性可以协助应用在数据库端确保数据的完整性, 并进行日志记录, 数据校验等操作
- 现在触发器只支持**行级触发**, 不支持语句级触发
	- 行级触发 : 每修改一次触发一次
	- 语句级触发 : 每执行一次语句触发一次, 不管影响多少行
- 使用别名 old 和 new 来引用触发器中发生变化的记录内容

**别名作用**
|触发器类型|new和old|
|-|-|
|insert型触发器|new表示将要或已经新增的数据|
|update型触发器|old表示修改前数据, new表示将要或已经修改后数据|
|delete型触发器|old表示将要或已经删除的数据|

### 语法

**创建**
- `each row` : 行级触发器
- 行级触发器涉及到多少行就触发几次
```mysql
create trigger trigger_name
before/after insert/update/delete
on tbl_name for each row
begin
    trigger_statement;
end;
```

**查看**
```mysql
show triggers;
```

**删除**
```mysql
drop trigger [schema_name.]trigger_name;
```

**示例01** : 通过触发器记录tb_user表的数据插入日志, 将插入日志记录到日志表user_logs中
```mysql
create trigger tb_user_trigger  
    after insert on tb_user  for each row  
begin  
    insert into user_logs(operation, operation_time, operation_id, operation_params) VALUES 
    ('insert', now(), new.id,  
      concat('id=', new.id, ',name=', new.name, 
      ',phone=', new.phone, ',email=', new.email, 
      ',profession=', new.profession, ',age=', new.age, 
      ',gender=', new.gender, ',status=', new.status, 
      ',createtime=', new.createtime));  
end;  
-- 尝试插入  
insert into tb_user(id, name, phone, email, profession, age, gender, status, createtime)  
VALUES (25,'二皇子','18809091212','erhuangzi@163.com','软件工程',23,'1','1',now());
```
