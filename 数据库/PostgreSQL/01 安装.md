
# docker 安装

安装命令
```bash
docker run -d --name pg-study -p 5432:5432 -e POSTGRES_USER=root -e POSTGRES_PASSWORD=root -e POSTGRES_DB=mypg_db -e TZ=Asia/Shanghai -v pgdata:/var/lib/postgresql/data postgres:16.14
```

```bash
docker run -d --name pg-vector -e POSTGRES_PASSWORD=root -p 5432:5432 pgvector/pgvector:pg16
```
