# 数据结构

- 作为一种键值型数据库, key一般为String类型, 但value类型多样 (前5种更常见, 为基本类型, 后三种为特殊类型)
- 官网和 cli 中使用 `help @类型` 都可以用来获取指令的帮助
- [Commands | Docs](https://redis.io/docs/latest/commands/)
- String : 字符串
- Hash : 哈希表
- List : 链表
- Set : 集合
- SortedSet : 有序集合
- GEO : 地理坐标
- Bitmap
- HyperLog

# 通用命令

- 通用命令是部分数据类型的, 都可以使用的指令
- keys : 查看符合模板的所有key
	- 搜索过程使用通配, 查询较慢, 可能阻塞线程, 不建议生产环境使用
- del : 删除指定key, 可以批量删除, 返回删除的数量
- exists : 判断key是否存在
	- 参数 : 秒
- expire : 给一个key设置有效期, 到期key自动删除
- ttl : 查看key的剩余有效期
	- -2 : 已经被删除
	- -1 : 永久有效

# String类型

**概述**
- String类型, 也就是字符串类型, 是Redis中最简单的存储类型
- 其value是字符串, 不过根据字符串格式的不同可以分为3类
	- string : 普通字符串
	- int : 整数类型, 可以做自增自减操作
	- float : 浮点类型, 可以做自增自减操作
- 不管哪种格式, 其底层都是字节数组形式存储, 只不过编码方式不同
- 字符串类型最大空间不能超过512m

**常见命令**
- set : 插入或修改已经存在的String类型的键值对
- get : 根据key获取String类型的value
- mset : 批量插入多个String类型的键值对
- mget : 根据多个key获取多个Stirng类型的value
- incr : 让一个整型的key自增1
- incrby : 让一个整型的key自增并指定步长
	- 通过 `incrby key -1` 可以实现自减效果
- incrbyfloat : 让一个浮点类型的数字自增并指定步长
	- 浮点数没有默认增长, 必须指定步长
- setnx : 添加一个String类型的键值对, 前提是key不存在, 否则不执行
	- 和 `set k v nx` 效果一致
- setex : 添加一个String类型的键值对, 并指定有效期
	- 和 `set k v ex 时间` 效果一致

### Key层级格式

**概念**
- Redis中没有类似Table的概念, 则如何区分不同类型的key, 如用户id和商品id
- Redis的Key运行多个单词形成层级结构, 多个单词之间使用 `:` 隔开
	- 如 : `项目名:业务名:类型:id`
- 格式不固定, 根据自身需求添加或删除词条
- 如果value是一个Java对象, 则可以将对象序列化为JSON字符串后存储

# Hash类型

**概述**
- Hash类型, 也叫做散列, 其value是一个**无序字典**, 类似于Java中的HashMap结构
- String结构是将对象序列化为JSON字符串后存储, 对于需要修改对象中某个字段时很不方便
- Hash结构可以将对象中的每个字段单独存储, 可以针对**单个字段**做CRUD
 ![[数据库/Redis/Inbox/Pasted image 20250912160623.png]]

**常用命令**
- hset key field value : 插入或修改已经存在的hash类型key的field值
	- `hset heima:user:3 name Lucy`
- hget key field : 获取一个hash类型key的field值
	- `hget heima:user:3 name`
- hmset : 批量插入多个hash类型key的field值
	- `hmset heima:user:4 name majinliang age 18 gender male`
- hmget : 批量获取多个hash类型key的field值
	- `hmget heima:user:4 name age gender`
- hgetall : 获取一个hash类型的key中的所有field和value
	- `hgetall heima:user:4`
- hkeys : 获取一个hash类型key中所有的fields
	- `hkeys heima:user:4`
- hvals : 获取一个hash类型key中所有的value
	- `hvals heima:user:4`
- hhincrby : 让一个hash类型的key字段值自增并指定步长
	- `HINCRBY heima:user:4 age 2`
- hsetnx : 添加一个hash类型key的field值, 前提是field不存在, 否则不执行
	- `HSETNX heima:user:4 name zhuangxiaohan`
	- `HSETNX heima:user:4 salary 50000`

# List类型

**概述**
- Redis中的List与Java中的LinkedList类似, 可以看作是一个**双向链表**结构
- 既可以支持正向检索, 也可以支持反向检索
- 特征
	- 有序
	- 元素可以重复
	- 插入和删除速度快
	- 查询速度一般
- 常用于存储有序数据的场景

**命令**
- lpush key  element : 向列表左侧插入一个或多个元素
	- `lpush users 1 2 3`
	- 按照书写顺序插入 (先1, 再2, 再3)
- lpop key : 移除并返回列表左侧的第一个元素, 没有则返回nil
	- `lpop users 2`
	- 从左侧连续取2个元素
- rpush key element : 向列表右侧插入一个或多个元素
	- `rpush users 4 5 6`
- rpop key : 移除并返回列表右侧的第一个元素, 没有则返回nil
	- `rpop users 2`
- lrange key star end : 返回一段角标范围内的所有元素
	- `LRANGE users 1 2`
	- 角标从0开始计算
- blpop 和 brpop : 类似lpop和rpop, 但是没有元素时不直接返回nil, 而是等待一段指定的时间
	- `blpop users2 100`

# Set类型

**概述**
- Redis的Set结构于Java中的HashSet类似, 可以看作是一个value为null的HashMap
- 因为也是一个hash表, 所以具有与HashSet类似的特征
	- 无序
	- 元素不可重复
	- 查找快
	- 支持交集, 并集, 差集等功能

**常见命令**
- sadd key member ... : 向一个set中添加一个或多个元素
	- `sadd s1 a b c`
- srem key member ... : 移除set中的指定元素
	- `srem s1 a`
- scard key : 返回set中元素的个数
	- `SCARD s1`
- sismember key member : 判断一个元素是否存在于set中
	- `SISMEMBER s1 a`
- smembers key : 获取set中的所有元素
	- `smembers s1`
- sinter key1 key2 ... : 求多个集合的交集
- sdiff key1 key2 ... : 求key1与key2的差集, 相当于key1-key2
- sunion key1 key2 ... : 求key1与key2的并集, 重复元素只记录一次

# SortedSet类型

**概述**
- Redis中的SortedSet是一个可排序的Set集合, 与Java中的TreeSet类似, 但是底层数据结构相差较大
- SortedSet中每一个元素都带有一个score属性, 可以基于score属性对元素进行排序, 底层的实现是一个跳表(SkipList) 加 hash表
- SortedSet具有以下特性
	- 可排序
	- 元素不重复
	- 查询速度快
- 由于这些特性, SortedSet常用来实现排行榜等功能

**命令**
- zadd key score member : 向一个sorted set中添加一个或多个元素, 如果存在则更新其score值
	- `zadd ss1 85 Jack 89 Lucy 82 Rose 95 Tom 78 Jerry 92 Amy 76 Miles`
- zrem key member ... : 移除sorted set中的一个指定元素
	- `zrem ss1 Tom`
- zscore key member : 获取sorted set中的指定元素的score值
	- `ZSCORE ss1 Amy`
- zrank key member : 获取sorted set中的指定元素的排名
	- `zrank ss1 Rose`
- zcard key : 返回sorted set中元素的个数
	- `zcard ss1`
- zcount key min max : 统计score值在给定范围内的所有元素的个数
	- `ZCOUNT ss1 0 80`
- zincrby key increment member : 让sorted set中的指定元素自增, 步长为指定的increment值
	- `ZINCRBY ss1 2 Amy`
- zrange key min max : 按照score排序后, 获取指定排名范围内的元素
	- `ZRANGE ss1 0 2`
- zrangebyscore key min max : 按照score排序后, 获取指定score范围内的元素
	- `ZRANGEBYSCORE ss1 0 80`
- zinter key1 key2 ... : 求多个集合的交集
- zdiff key1 key2 ... : 求key1与key2的差集, 相当于key1-key2
- zunion key1 key2 ... : 求key1与key2的并集, 重复元素只记录一次
- 所有排名默认升序, 如果需要降序, 则在命令的z字母后**添加rev**即可
	- `zrevrank ss1 Rose`
