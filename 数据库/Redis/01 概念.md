
# NoSQL

**概念**
- Redis是一个键值型数据库, 也是一种NoSQL类型数据库
- SQL (Structured Query Language) : 关系型数据库
- NoSQL : 非关系型数据库

**差异**
- 关系型数据库
	- 结构化 (Structured)
		- 指数据库中的数据有固定的结构要求, 同时有约束等对数据类型的要求
		- 在MySQL中, 这种固定的格式要求即为 表
		- 结构相对固定, 不建议对结构做修改
	- 关联的 (Relational)
		- 在SQL中, 各个表之间可能存在一定的联系, 由数据库进行维护
		- 如MySQL中的外键约束等, 将表之间建立关联
	- SQL查询
		- 关系型数据库中查询靠SQL语句进行
		- 关系型数据库之间使用同一套语法, 相互之间基本可以共用
	- ACID
		- 在关系型数据库中, 通常支持事务的ACID性质
	- 磁盘存储
	- 垂直扩展
- 非关系型数据库
	- 非结构化
		- 可以以键值对的形式存储, 通常对数据不做约束或较少约束
		- 也可以以文档document的形式存储, 也以JSON类型存储
		- 同时还有其他类型的存储方式, 如Graph
	- 无关联的
		- 数据之间靠JSON存储, 相互不存在关联
		- 如果想要建立关系, 需要靠程序员自身维护, 数据库不做处理
	- 非SQL
		- 操作相对简便, 但是不够统一
		- 不同非关系型数据库之间通常使用不同的命令进行数据库操作
	- BASE
		- 非关系型数据库通常无事务或者无法满足事务全部特性, 只能满足基本操作, 故称为 BASE
	- 内存存储
	- 水平扩展


# 认识Redis

**概念**
- Redis诞生于2009年 , 是一个基于内存的键值型NoSQL数据库
- Remote Dictionary Server , 远程词典服务器
- Redis命令文档 : [Commands | Docs](https://redis.io/docs/latest/commands/)

**特点**
- 键值型 , value支持多种不同的数据结构, 功能丰富
- 单线程, 每个命令都具有原子性, 线程安全
- 低延迟, 速度快 (基于内存 , IO多路复用 , 编码良好)
- 支持数据持久化
- 支持主从集群, 分片集群
- 支持多语言客户端

**启动与配置**
- 任意路径下使用 `redis-server` 即可运行redis
- 如果需要默认后台启动, 则需要修改部分配置文件
	- 在 Redis 安装包下的 redis.conf 文件中进行修改
	- bind改为 `0.0.0.0` (任意IP访问, 生成环境不允许)
	- daemonize改为 `yes` (默认后台运行)
	- requirepass 为redis添加密码
- 其他配置如下
	- port : 端口, 默认6379
	- dir . : 工作目录, 默认为当前目录
	- database 1 : 设置数据库数量 , 默认16, 编号 0-15
	- maxmemory 512mb : 设置redis可使用的最大内存
	- logfile "redis.log" : 日志文件, 默认为空, 不记录日志
- `redis redis.conf` : 使用配置项启动redis

**开机自启动**
- 添加系统服务文件 `/etc/systemd/system/redis.service`
- 重启daemon : `systemctl daemon-reload`
- 启动服务 : `systemctl start redis`
- 开机自启动 : `systemctl enable redis`
- 内容如下
```service
[Unit]
Description=redis-server
After=network.target

[Service]
Type=forking
ExecStart=/usr/local/bin/redis-server /usr/local/src/redis-6.2.14/redis.conf
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

# Redis客户端

### 命令行

- redis安装完成后自带命令行客户端 : redis-cli
- 使用 : `redis-cli [options] [commands]`
- 常见参数
	- `-h 127.0.0.1` : 指定redis服务器IP, 默认本机
	- `-p 6379` : 指定redis连接端口, 默认6379
	- `-a 123321` : 指定访问redis密码

**常用命令**
- `auth 密码` : 连接到redis后输入登录密码
- `ping` : 与客户端做心跳测试, 成功返回 `pong`
- `select 库` : 切换使用的库
