
# 基础概念

**概念**
- 反射允许对封装类的字段, 方法和构造函数的信息进行编程访问

**class对象**

获取 class 对象有三种方式
1. `Class.forName("全类名");`
	- 在源代码阶段获取, 不需要字节码加载到内存
	- 最常用, 使用该方式获取字节码对象
2. `类名.class`
	- 字节码加载到内存后, 可以使用该方法获取
	- 通常作为参数进行传递
3. `对象.getClass()`
	- 使用字节码创建对象后, 可以在运行阶段使用该方法获取

**示例**
```java
// Class.forName("全类名")  
Class<?> myClazz = Class.forName("com.itheima.myreflect01.Student");  
// 类名.class  
Class<Student> myClazz2 = Student.class;  
// 对象.getClass()  
Student student = new Student();  
Class<? extends Student> myClazz3 = student.getClass();  
```

# 反射基础

**反射获取参数**
- Java 中一切皆对象, 则字节码中的各个组成部分也可以作为对象
- 类构造方法对象: `Constructor`
- 类成员变量对象: `Field`
- 类成员方法对象: `Method`

### 构造方法

- `getConstructors()`: 获取所有**公共**构造方法对象的数组
- `getDeclaredConstructors()`: 获取所有构造方法对象的数组
- `getConstructor(Class<?>... parameterTypes)`: 单个公共构造方法对象
- `getDeclaredConstructor(Class<?>...parameterTypes)` : 单个构造方法对象
- `int getModified()` : 获取方法权限修饰符, 返回值为整数
- `getParameterCount()` : 获取参数个数
- `getParameterTypes()` : 获取参数类型
- `getParameter()` : 获取方法内所有参数
- `newInstance()` : 直接使用字节码创建实例对象, 要求必须可用
- `setAccessible()` : 临时取消权限校验, 又称为暴力反射

**示例**
```java 
Constructor<?>[] cons = clazz.getConstructors();  
Constructor<?>[] dcons = clazz.getDeclaredConstructors();   
Constructor<?> conNullArgs = clazz.getConstructor();  
Constructor<?> conString = clazz.getConstructor(String.class);  
Constructor<?> conInt = clazz.getConstructor(int.class);
Constructor<?> conAll = clazz.getDeclaredConstructor(String.class, int.class);
int modifiers = conInt.getModifiers();  
Parameter[] parameters = conString.getParameters();  
conAll.setAccessible(true);  
Student stu = (Student) conAll.newInstance("张三", 23);  
```

### 成员变量

- `getFields()` : 返回所有公共成员变量对象的数组
- `getDeclaredFields()` : 返回所有成员变量对象的数组
- `getField(String name)` : 返回单个公共成员变量对象
- `getDeclaredField(String name)` : 返回单个成员变量对象
- `getType()` : 获取成员变量权限修饰符
- `getName()` : 获取成员变量名 
- `getType()` : 获取成员变量类型 
- `setAccessible()` : 临时取消权限校验
- `get(Object)` : 获取对象中对应的成员变量中数据
- `set(Object, value)` : 修改对象变量中记录的值

**示例**
```java
// 获取所有公共成员变量
Field[] fields = clazz.getFields();  
// 获取所有成员变量  
Field[] declaredFields = clazz.getDeclaredFields();  
// 根据变量名获取公共成员变量
Field gender = clazz.getField("gender");  
// 根据变量名获取成员变量
Field name = clazz.getDeclaredField("name");  
// 获取成员变量权限修饰符  
int modifiers = name.getModifiers();   
// 获取成员变量名  
String nameStr = name.getName();   
// 获取成员变量类型  
Class<?> type = name.getType();  
// 获取对象变量中的数据  
Student student = new Student("张三", 23, "男");  
name.setAccessible(true);  
Object value = name.get(student);
// 修改对象变量中记录的值  
name.set(student, "李四");  
```

### 成员方法

- `getMethods()`: 获取所有**公共**成员方法对象的数组, 包括继承的
- `getDeclaredMethods()`: 获取所有成员方法对象的数组, 不包括继承的
- `getMethod(name, parameterTypes...)`: 单个公共成员方法对象
- `getDeclaredMethod(name, parameterTypes...)` : 单个成员方法对象
- `int getModified()` : 获取方法权限修饰符, 返回值为整数
- `getName()` : 获取方法名称
- `getParameterCount()` : 获取参数个数
- `getParameterTypes()` : 获取参数类型
- `getParameter()` : 获取方法内所有参数
- `getExceptionTypes()` : 获取方法抛出的异常
- `invoke(Object, args...)` : 执行对象的该方法, args 为传入的参数
- `setAccessible()` : 临时取消权限校验

**示例**
```java
// 获取其中所有的公共方法对象, 包括继承得来的  
Method[] methods = clazz.getMethods();  
// 获取其中所有的方法对象, 不包括继承得来的, 但是可以获取私有方法  
Method[] declaredMethods = clazz.getDeclaredMethods();  
// 获取对应参数类型的方法  
Method eatMethod = clazz.getDeclaredMethod("eat", String.class);  
// 获取方法的修饰符  
int modifiers = eatMethod.getModifiers();  
// 获取方法名称  
String name = eatMethod.getName();  
// 获取方法形参  
Parameter[] parameters = eatMethod.getParameters();  
// 获取方法抛出的异常  
Class<?>[] exceptionTypes = eatMethod.getExceptionTypes();  
// 运行该方法  
// 获取方法返回值  
Student student = new Student();  
eatMethod.setAccessible(true);  
Object result = eatMethod.invoke(student, "苹果");  
```

### 反射总结
**作用**
- 获取一个类里面所有的信息, 获取到之后, 再执行其他业务逻辑
- 结合配置文件, 动态的创建对象并调用方法

# 动态代理

- 无侵入式的给代码增加额外的功能
- 对象可以通过代理转移部分职责
- 对象有什么方法需要被代理, 代理中就要有对应的方法
- 通过接口, 实现代理与对象之间方法的一致性, 想要代理的方法在接口中

**创建动态代理对象**
- `java.lang.reflect.Proxy` 类: 提供了为对象产生代理对象的方法
- `public static Object newProxyInstance(ClassLoader loader, Class<?>[] interfaces, InvocationHandler h)`
- 参数1: 用于指定用哪个**类加载器**, 去加载生成的代理类
- 参数2: 指定接口, 这些接口用于指定生成的代理类的结构
- 参数3: 用于指定生成的代理类对象要做什么事情

**示例**
- 创建代理
```java
public static Star createProxy(BigStar bigStar) {  
    // 使用Proxy类创建代理  
    Star star = (Star) Proxy.newProxyInstance(  
            ProxyUtil.class.getClassLoader(),  
            new Class[]{Star.class},  
            new InvocationHandler() {  
                @Override  
                public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {  
                    if("sing".equals(method.getName())) {  
                        System.out.println("准备话筒, 收钱");  
                    } else if("dance".equals(method.getName())) {  
                        System.out.println("准备场地, 收钱");  
                    }  
                    return method.invoke(bigStar, args);  
                }  
            }  
    );  
    return star;  
}
```
- 使用代理
```java
public static void main(String[] args) {  
    // 获取代理对象  
    BigStar bigStar = new BigStar("鸡哥");  
    Star proxy = ProxyUtil.createProxy(bigStar);  
    String result = proxy.sing("基尼太美");  
    proxy.dance("baby");  
    System.out.println(result);  
}
```
