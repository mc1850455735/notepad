**Java安装路径各个文件夹含义**
- bin : 存放了各种工具和命令, 如javac和java
- conf : 存放了相关配置文件
- include : 存放了一些平台特定的头文件
- jmods : 存放了各种模块
- legal : 存放了各个模块的授权文档
- lib : 存放了工具的一些补充JAR包

**编译与运行**
- javac : 编译
	- `javac xxx.java`
	- 将java源代码编译成为class字节码文件
- java : 运行
	- `java xxx`

**环境变量**
- 现在Java安装时, 会默认将 `java` , `javac` , `javaw` , `jshell` 添加到 `C:/Program Files/Common Files/Oracle/Java/javapath` 文件夹中并将该文件夹添加到系统环境变量中
- 由此可以做到安装后即可全路径编译运行Java源码, 但是由于工具不够全面, 很多时候还是需要手动配置环境变量

# Java发展

**版本**
- 长期支持版本 (LTS)
- 8.0 , 17.0 , 21.0

**三大使用平台**
- JavaSE
	- Java语言的**标准版**, 可以用于桌面应用的开发
	- 是其他两个版本的**基础**
- JavaME
	- Java语言的**小型版**, 可以用来做嵌入式电子设备或者小型移动设备的开发
	- 目前已经被Android等替代, 但替代品的核心仍以Java或其衍生语言为主
- JavaEE
	- Java语言的**企业版**, 用于Web方向的网站开发

**主要特征**
- 面向对象
- 安全性
- 多线程
- 安全易用
- 开源
- 跨平台

**Java跨平台**
- 一次编译, 到处运行
- Java如何实现跨平台
	- Java的跨平台是通过虚拟机实现的
	- Java文件编译成为字节码后, 在Java虚拟机(JVM)中进行运行
	- 针对不同的操作系统, 只需要安装不同的虚拟机即可
- Java是一种混合型语言, 在Java运行中, 即存在编译, 也存在解释
	- 编译 : Java文件编译成为字节码文件
	- 解释 : 字节码在虚拟机中通过解释的方式执行

# JRE和JDK

- JDK (Java Development kit) : Java开发工具包
	- JVM (Java Virtual Machine) : Java虚拟机, 真正运行Java代码的地方
	- 核心类库 : Java提前定义好的一些类功能
	- 开发工具 : 如 javac , java , jhat , jdb等
- JRE (Java Runtime Environment) : Java运行环境
	- JVM
	- 核心类库
	- 运行工具
- JDK包含了JRE , JRE包含了JVM
