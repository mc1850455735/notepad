
# 双列集合

**特点**
- 双列集合一次需要存一对数据, 分别为键和值
- 键不能重复, 值可以重复
- 键和值是一一对应的, 每一个键只能找到自己对应的值
- 键值整体称为键值对, 在 Java 中叫做 `Entry对象`

### Map

**常见API**
- Map是双列集合的顶层接口, 他的功能是全部双列集合都可以继承使用的
- `V put(K key, V value)` : 添加元素
	- 有两个不同的作用: `添加` 和 `覆盖`
	- 添加数据时, 如果键不存在, 则直接添加该键值对, 返回值为 `null`; 如果键存在, 则修改键中的值, 并将键中的原值返回
- `V remove(Object key)` : 根据键删除键值对元素
	- 返回值为被删除键值对的值
- `void clear()` : 移除所有的键值对对象
- `boolean containsKey(Object key)` : 判断集合是否包含指定的键
- `boolean containsValue(Object value)` : 判断集合是否包含指定的值
- `boolean isEmpty()` : 判断集合是否为空
- `int size()` : 集合的长度, 也就是集合中键值对的个数

**遍历**
- 键找值: 通过 `keySet()` 方法获得键的单列集合
```java
for (String key : map.keySet()) {  
    System.out.println(map.get(key));  
}
```
- 键值对: 依次获取每个键值对对象, 通过 `getKey` 获取键, `getValue` 获取值
```java
for (Map.Entry<String, String> entry : map.entrySet()) {  
    System.out.println("Key = " + entry.getKey());  
    System.out.println("Value = " + entry.getValue());  
}
```
- Lambda 表达式
```java
// lambda表达式  
map.forEach((k, v) -> System.out.println(k + "=" + v));
```

### HashMap

**概述**
- `HashMap` 是 Map 的一个实现类
- 特点都是由**键**决定的:  无序, 不重复, 无索引
- 没有需要额外学习的特有方法, 与 Map 接口中的方法一致
- `HashMap` 与 `HashSet` 底层原理相同, 都是哈希表结构, 哈希值只与**键**有关
- 当某节点链表长度大于8且数组长度大于等于64时, 对应的节点中的链表就会转为红黑树进行存储

### LinkedHashMap

**概述**
- 由键决定: 有序, 不重复, 无索引
- 是 `HashMap` 的子类, 与 `HashMap` 的方法一致, 没有特有方法
- 这里的**有序**指的是保证存储和取出元素的顺序是一致的
- 底层为哈希表, 只是每个键值对多出了一个双向链表记录存储的顺序

### TreeMap

**概述**
- 由键决定特性: 不重复, 无索引, 可排序
- `TreeMap` 底层与 `TreeSet` 一致, 都是红黑树结构
- 可排序: 对键进行排序
- 排序规则参考 TreeSet中的介绍

### 总结
- 双列集合使用时, 默认按照以下方法进行选择
- 默认使用 HashMap, 因为其效率最高
- 如果需要存取有序, 则使用 LinkedHashMap
- 如果需要进行排序, 使用 TreeMap

# 其他

### 可变参数

**概述**
- 可变参数: 方法形参的个数可以发生变化
- 格式: `属性... 名称`

**注意事项**
- 可变参数的底层就是一个**数组**, 只是 Java 会自动根据可变参数创建该数组
- 同一个方法中最多只能存在一个可变参数
- 同一个方法中, 如果存在多个参数, 那么可变参数必须**在最后**

### 集合工具类

- java.util.Collections 是一个集合工具类
- 常用 API
	- `boolean addAll(Collection<T> c, T... elements)` : 批量添加元素
	- `void shuffle(List<?> list)` : 打乱 List 集合元素的顺序
	- `void sort(List<?> list)` : 排序
	- `void sort(List<?> list, Comparable<T> c)` : 以指定的规则排序
	- `int binarySearch(List<T> list, T key)` : 二分法查找元素下标
	- `void copy(List<T> dest, List<T> src)` : 拷贝集合中元素
	- `int fill(List<T> list, T obj)` : 以指定元素填充集合
	- `void max/min(Collection<T> coll)` : 根据默认排序获得最大最小值
	- `void swap(List<?> list, int i, int j)` : 交换集合中指定下标元素

### 不可变集合

**概念**
- 即不能被修改的集合, 不想被别人修改时使用
- 如果某个数据不能被修改, 把他防御性的拷贝到不可变集合中是个好实践
- 当集合对象被不可信的库调用时, 不可变形式是安全的

**获取与使用**
- 在 List, Map, Set 等接口中, 都存在 `of` 方法用于获取不可变集合
- 当试图获取不可变 Map 或 Set 时, 要保证其中的**键是唯一**的
- Map 中的 of 方法参数数量有上限, 最多只能传入20个参数, 即10个键值对
	- 因为键值对没有办法进行可变参的设计
- 如果欲传输超过10个的键值对, 则可以使用 Map 中 `ofEntries` 方法
- `ofEntries(Extry<? extends K, ? extends V>... entries)`
- `toArray(T[])` 方法可以将单列集合成为数组, 如果参数中数组大小太小, 则其会根据实际数据的大小, 重新创建数组
- `JDK10` 后, 各个接口中还存在 `copyOf` 方法, 直接将可变集合转为不可变集合
