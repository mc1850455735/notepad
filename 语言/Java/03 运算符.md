
# 概念

**运算符**
- 对字面量或变量进行操作的符号

**表达式**
- 使用运算符把字面量或者变量连接起来, 符合Java语法的式子就被称为表达式

# 算术运算符

- `+` 
	- 数字相加
	- 字符串相加 : 从左到右依次相加
	- 字符相加 : 使用ASCII作为规则
- `-`
- `*`
- `/` : 整数除整数得整数
- `%`

**类型转换**
- 隐式转换 : 小变大
- 强制转换 : 大变小
	- `目标数据类型 变量名 = (目标数据类型)数据; `
	- 可能导致溢出

# 自增运算符

- `变量++ / ++变量` : 变量值+1
- `变量-- / --变量` : 变量值-1

**前置后置区别**
- 前置 : 先增加再使用
- 后置 : 先使用再增加

# 赋值运算符

- `+=` , `-=` , `*=` , `/=` 等底层都隐藏了一个强制类型转换
- 保证对于如short类型变量s , `s += 1` 不会出现类型问题

# 关系运算符

- 运算结果都是boolean类型

# 逻辑运算符

- `&` : 逻辑与
- `|` : 逻辑或
- `^` : 逻辑异或
- `!` : 逻辑非

**短路逻辑运算符**
- 如果在左边部分已经被认定为条件成立 / 不成立, 则不会继续向下执行
- `&&` : 短路逻辑与
- `||` : 短路逻辑或

# 三元运算符

**格式**
`关系表达式 ? 成立结果 : 不成立结果`
