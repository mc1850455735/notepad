# 注释

- 单行注释 : `//`
- 多行注释 : `/*  */`
- 文档注释 : `/**  */`

**注意**
- 注释不要嵌套

# 关键字

- 关键字是被Java赋予了特殊含义的英文单词
- 关键字字母全部小写

### class
- class关键字用于定义一个类
- 类是Java最基本的组成单元

**语法**
```java
class 类名{
    ...
}
```

# 字面量

**类型**
- 整数
- 小数
- 字符串
- 字符 
	- `\t` : 打印时, 加上前面字符串长度补齐到8或者8的倍数
- 布尔
- 空 : null不能直接打印, 如果想要打印, 只能打印它的字符串

# 变量

- 在程序执行过程中, 值有可能发生改变的量
- 一条语句可以定义多个变量
	- `int a,b,c;`

### 数制
- JDK7+版本中
- 二进制 : 代码中以 `0b` 开头
- 十进制 : 不需要加前缀
- 八进制 : 代码中以 `0` 开头
- 十六进制 : 代码中以 `0x` 开头

### 数据类型

- 基本数据类型
	- 整数
		- byte : 运算时会先提升为int
		- short : 运算时会先提升为int
		- int
		- log
	- 浮点数
		- float
		- double
	- 字符
		- char : 运算时会先提升为int
	- 布尔
		- boolean
- 引用数据类型

### 标识符
- 给类, 方法, 变量起的名
- 区分大小写

**命名建议**
- 小驼峰
	- 方法
	- 变量
- 大驼峰
	- 类名

# 键盘录入

**使用Scanner**
- 导包
	- `import java.util.Scanner`
- 创建对象
	- `Scanner sc = new Scanner(System.in);`
- 接收数据
	- `int i = sc.nextInt();`
