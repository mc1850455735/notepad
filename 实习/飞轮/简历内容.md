
### AgentHub——多用户 AI Agent 会话编排平台
技术栈：Go、PostgreSQL、Docker、Vue、SSE、Codex App Server

- 基于 `Session → Thread → Turn` 建模持久化多轮 Agent 会话，通过状态机管理任务排队、执行、完成、中断和恢复流程。
- 设计 Session 级 Docker Runtime 隔离，为不同会话挂载独立 Workspace、Sandbox、环境变量和模型凭证，并实现 Runtime 启动、恢复与回收。
- 通过 Bridge 适配 Codex、Claude、Gemini、Grok 等不同模型协议，统一模型发现、流式事件、工具调用和执行结果处理。
- 使用 PostgreSQL 持久化 Session、Turn、Schedule 和状态迁移事件，结合文件系统保存 transcript、附件、日志及 Agent 产物。
- 建设渠道健康检查和多账号凭证池治理，根据周期巡检结果过滤异常账号，并为巡检失败和无健康账号场景设计降级策略。
- 接入飞书、Jenkins、TeamCity 和定时任务入口，通过消息映射、幂等控制及失败回退将外部事件统一转换为 Agent Session。

### AgentHub——多模型 Agent Runtime 与会话编排平台
技术栈：Go、Docker、PostgreSQL、Codex App Server、Claude/Gemini/Grok CLI

- 构建持久化 Agent 会话模型，使同一 Session 能够复用原生 Thread 连续执行多个 Turn，并支持完成后继续对话和运行中人工介入。
- 为每个活跃 Session 提供独立 Docker Runtime，隔离模型凭证、工具环境、Workspace 和运行状态。
- 统一适配多家模型的 Server/CLI 协议，实现模型动态发现、流式事件处理、能力差异兼容以及失败回退。
- 接入 Owner 级长期记忆和 Schedule 级摘要记忆，在 Agent 生命周期内完成 recall、上下文注入和 retain。
- 建设 Agent 运行诊断体系，记录状态迁移、工具调用、Turn 结果和 Runtime 日志，支持按 Session、Thread、Turn 定位执行故障。
