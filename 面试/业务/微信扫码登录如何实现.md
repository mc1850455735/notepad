
微信扫码登录本质上是基于手机微信已有登录态完成的一种授权登录。网页端先向服务端申请一个临时登录请求，服务端生成一个短期有效、一次性的二维码，二维码中通常包含登录请求 ID 或 OAuth 授权地址。网页端展示二维码后，通过轮询、长轮询或 WebSocket 等方式等待登录状态。

用户用手机微信扫码后，微信服务器根据手机端已有登录态识别用户，并把该登录请求状态改为已扫码。随后手机端展示确认页，用户确认后，微信服务器生成临时授权码 code，并回调业务服务器。业务服务器再用 code、appid 和 secret 向微信服务器换取 access_token、openid 或 unionid，然后根据这些身份标识查找或创建本地用户，最后生成自己系统的 session 或 JWT，完成网页登录。

它的安全性主要来自几个方面：二维码本身不是账号密码，而是短期有效的一次性请求；真正的身份校验依赖手机微信已有登录态；登录前需要用户手动确认；OAuth 流程中还会通过 state、redirect_uri 白名单、HTTPS、code 一次性使用等机制防止伪造和劫持。
