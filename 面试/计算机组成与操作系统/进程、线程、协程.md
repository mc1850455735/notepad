
# 说一下进程、线程、协程分别是什么，他们之间的区别是什么？

进程是操作系统资源分配和隔离的基本单位，不同进程通常具有独立的虚拟地址空间；
线程是 CPU 调度的基本单位，同一进程内的线程共享相同的虚拟地址空间，但是具有各自独立的栈空间和寄存器上下文；
协程是用户态的轻量级调度单元，由用户态运行时或协程调度器进行调度，通常具有更低的创建和切换成本。

# 线程崩溃会导致进程崩溃吗？为什么？

线程异常退出不一定导致进程崩溃。在 Java 中，普通的未捕获异常通常只会终止当前线程，因为每个线程有独立的执行栈和执行流。但线程之间共享同一个进程地址空间，如果某个线程触发了 SIGSEGV、JVM Fatal Error 等进程级致命错误，操作系统可能终止整个进程，因此所有线程都会一起结束。
