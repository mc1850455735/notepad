
# Java 优先队列的结构，小根堆是如何组织的，堆排序是否是一个稳定的排序？

Java 的 PriorityQueue 优先队列默认使用小根堆实现。该小根堆是一个二叉堆。
二叉堆有两个核心特点：
1. 在结构上，二叉堆是一个完全二叉树，除最后一层外每一层都是满的，最后一层的节点从左到右进行排列；
2. 同时，二叉堆(小根)中的节点满足堆的性质，父节点的值始终小于等于子节点。

在 Java 的优先队列中，使用数组对小根堆进行组织。

小根堆中，通过两个核心操作进行堆性质的维护：
- 插入：插入时，将新元素放到数组末尾，再不断与父节点进行比较，直到满足小根堆性质；
- 删除：删除时，将根节点移出，再将数组最后一个元素移到根节点，再不断与更小的子节点进行比较，直到满足小根堆性质。

堆排序是一种**不稳定**的排序算法。排序时，如果子节点中存在相同值的元素，那么原本在前的元素就可能被交换到后面：
```
原数组：
[5A, 5B, 3]

第一次交换堆顶与末尾：
[3, 5B, 5A]

调整剩余堆：
[5B, 3, 5A]

第二次交换：
[3, 5B, 5A]
```
