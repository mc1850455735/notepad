
# 大模型微调

## 什么是微调

微调就是使用预训练的大模型，在不从头训练模型的情况下，**使用自己的数据对模型进行定向训练**，使其更接近自己的领域内。预训练模型就像是一个什么都会一点的全才，而预训练后的专有模型则是某个领域内的专家。

虽然现在大模型已经能力很强，但是通常存在以下问题，如：
- 风格不稳定，回答时而过长时而过短。
- 对特定场景下回答方式不规范，不能有效遵循业务规则。
- 在相关专业场景下，如医疗、法律、金融等适配不足。

微调的目的不是为了给予 LLM 新知识，而是为了纠正行为、强化模式、适配风格。

## 常见微调方式

**伪微调** Prompt Engineering
- 不更改模型参数，仅靠 Prompt 约束模型行为。
- 成本最低，但是效果有限。

**全参数微调** Full Fine-tuning
- 所有参数都进行训练
- 成本最高，个人或中小团队实现不现实。

**参数高效微调** PEET
- LoRA
	- 冻结原模型，只训练少量低秩矩阵。
	- 训练快，显存需求低，可叠加多个 LoRA。
- QLoRA
	- 在 LoRA 的基础上做 4-bit 量化。
	- 个人用户可用。
- Adapter / Prefix Tuning
	- 插入小模块
	- 调整输入前缀
