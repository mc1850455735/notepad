
# TCP 粘包拆包

## 介绍一下什么是 TCP 粘包拆包

由于 TCP 是一个面向字节流的协议, 在发送消息时, 不会理解上层语义, 只会对字节流进行发送或接受, 因此可能出现上层的单个消息被拆分成为多个包发送, 或者上层的多个消息被包装进同一个包进行发送.

为此, 使用 TCP 发送消息时, 需要采用一定的手段避免.

## 如何解决 TCP 粘包拆包问题

1. 上层用户固定每条消息的长度, 长度不足的直接补足
2. 指定一种分隔符, TCP 接收到以后按照分隔符对应用层消息进行拆分
3. 长度字段 + 消息字段. 先按照固定长度传输一个表示消息体长度的包, 再根据该信息接受后续消息字段.
4. 使用 HTTP, WebSocket, Protobuf 等具有明确结构和长度信息的协议
