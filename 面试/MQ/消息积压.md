
# 为什么会出现消息积压，如何处理大量消息积压？

当生产速度大于消费速度时，就会出现消息积压。常见的出现消息积压的原因如下：
- 生产流量突然增加：秒杀、大促等场景
- 消费者性能不足：消费者处理慢，CPU 性能不足 
- 下游服务响应慢：慢 SQL、Redis 响应慢、外部 API 延迟
- 消费者发生故障：消费者宕机，网络故障等
- 消费频繁失败：消费失败后持续重试，阻塞后续消息
- 分区数量不足：Kafka Partition 较少，限制了消息并行度
- 频繁 Rebalance
